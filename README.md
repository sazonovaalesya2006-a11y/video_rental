# Система проката видеокассет

Учебный проект по дисциплине «Конструирование программного обеспечения».

## Описание

Консольное приложение для автоматизации пункта проката видеокассет: учёт фильмов, кассет и клиентов, оформление проката и возврата.

## Стек технологий

- Python 3.10+
- Git / GitHub
